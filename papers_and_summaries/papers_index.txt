LIPIcs.SNAPL.2017.8.pdf - Dill
 - this paper goes into the current difficulties of intermittent computing operation, namely:
 - - control flow after shutdown and start (where does the program restart from?)
 - - memory inconsistency (data rolled back to a checkpoint after a restart, so data is lost)
 - - environmental sensor concurrency (sensors usually operated on interrupts, which can be affected by shutdowns)
 - - energy storage and distribution
